# 发布包隐私说明 / Release privacy notes

本仓库提供可复用工作流、脚本和通用版式。论文项目与技能仓库应分开保存。

## 本发布版

- 参考文档中的任务示例已经泛化，不保留个人论文题名、方法专名、原文页码或文库记录。
- 五页 PPTX 模板从零构建，只包含通用演示标签和原生可编辑对象，不复用旧论文图片或研究流程。
- PPTX 检查覆盖元数据、幻灯片文字、备注、隐藏内容、媒体、外部关系和嵌入对象。
- README 图片来自新通用示意图或新模板，不使用个人论文截图。
- 不打包个人文稿、实验数据、EndNote 文库、检索库、会话日志、缓存或私有审计材料。

这些说明针对发布的文件版本。Git历史、其他分支、旧克隆、fork和第三方缓存应单独处理，不能由当前文件检查推断已经删除。

## 使用者自己的文件

请把文稿、数据、文库和检索结果保留在私有论文工作目录。检索索引和审计记录可能含原文与完整本地路径；它们不属于可公开的技能资源。

分享定制版前，除搜索文本外，还应检查图片像素、Office作者属性、备注、隐藏页、对象名称、嵌入附件和外链。不要把凭据写入示例命令。

---

This repository contains reusable workflows, scripts, and generic layouts. Keep the skill repository separate from private research projects.

For this release, task examples are generalized and the five-slide PPTX is built from scratch with generic editable objects. It does not reuse private manuscript images or research-specific diagrams. Package checks cover text, Office metadata, notes, hidden content, media, relationships, and embedded objects. README images show generic diagrams and the new template. Personal manuscripts, measurements, citation libraries, retrieval indexes, logs, caches, and private audit records are excluded.

These statements apply to the released file version. Git history, other branches, old clones, forks, and external caches require separate handling; a clean current tree does not prove their removal.

Keep your own sources and generated indexes in a private paper workspace. Before redistributing a customized skill, inspect text and image pixels, author properties, notes, hidden slides, object names, attachments, and external links. Never include credentials in example commands.
