# 文献真实性核验与 CWYW 保真

适用于已有论文的参考文献真实性、著录信息、引文主张对应关系核验，以及已授权的定点修正。新增/替换文献、导入 EndNote 或重新生成 CWYW 的任务仍须读取[文献与 EndNote 工作流](literature-citation-workflow.md)对应部分；本文件不授权主动插引或改写原库。

## 1. 区分核验范围，继承已有授权

分别记录四个层次，不能互相替代：

1. 文献是否真实存在：题名、作者、出版载体与可访问的一手记录能否对应。
2. 著录是否准确：文献类型、年份、卷期、页码/文章号、作者、机构、DOI 等是否与所选版本相符。
3. 引文是否支持正文：具体判断与原文证据是否对应，证据阅读深度是否足够。
4. 是否与实际 EndNote 原库同一记录匹配：须有该库的实际记录身份依据，文档内嵌记录、CSV、字段计数或用户仅打开 EndNote 都不能证明原库已逐条匹配。

用户明确只检查真实性与信息、无需原库核对时，立即按该范围执行，不再索取 `.enl` 或 XML 导出，也不把打开 EndNote 作为必需前置。已有明确修订授权时直接修复工作副本中已证实的问题，不重复请求确认或只留建议；读库、写库、主动插引和整体刷新仍按其各自授权执行。配置中仅追问真正缺失且影响执行的信息。

## 2. 一手核验与版本判断

- 从当前论文可见文后条目、正文引文及可安全解析的内嵌记录建立对应表，记录显示编号、Record Number、数据库身份、题名、原值、核验值、来源链接/原文页、处理动作及最终状态。
- 优先出版社/期刊正式页面、DOI 注册元数据、正式论文 PDF、会议论文集、机构报告库等一手来源。查询结果摘要只是线索，题名近似不等于同篇。正文机制、实验与贡献归属必须读取相应原文，不能仅用题名或摘要证明细节。
- 区分 online-first 与正式卷期年份，按目标著录规范统一，不能混用在线年份与另一版本的卷页；重点检查将起始页错填为年份、错误末页、文章号当页码、技术报告当期刊、机构名当刊名、题名破损、复姓拆分、多位作者合并及 DOI 占位符。无 DOI 的真实文献不因此判伪。
- 正式版、预印本、早期在线版与排版变体须先辨认版本，不直接判为虚构或错误。正式 PDF 证实原值正确时撤回疑点并保留原值；不能为了统一格式改坏已正确的文献。
- 改写正文后引用仍紧邻被支持的判断，分辨他人成果与本文贡献。缺证时收敛授权范围内的主张或单列未核实项，不强塞无关引用、发明来源或将未找到写成已证明不存在。

## 3. 修正层次与字段保护

- 原稿和 EndNote 原库默认保留。用户要求“直接改”已证实著录问题时，按已确认修订范围定点更新文档可见条目；授权包含内嵌元数据且可安全解析时联动修正并记录差异，不只改记录后假定显示已同步。用户只授权文后显示或明确冻结字段代码时，保留内嵌元数据并在独立记录说明不同步及后续刷新风险，不扩展权限。保持 Record Number、数据库身份、显示编号、引用归属和原生 CWYW 结构。不直接编辑 `.enl/.Data` 二进制库。
- 含 `ADDIN EN.CITE/EN.REFLIST`、OMML、OLE、书签或绘图的段落不得用整段替换覆盖；使用字段感知的文字节点/记录级操作。元数据修正不等于重新选文献，也不授权手工重编号、移除字段代码或伪造可更新字段。
- 不调用全文 EndNote 扫描、`ENFormatBibliography`、`EN.REFLIST` 或全局字段更新来“检查格式”，除非本次明确授权。分页稳定后可更新获授权的普通导航字段；必须与 EndNote 域分开白名单执行。
- 保存前后检查完整字段指令、内嵌记录的可解析性与完整性、Record Number/数据库身份、显示结果及编号顺序。字段数量相同不足以证明保真；尤其旧版二进制 `w:fldData` 可能被 Word 保存截断，应核对完整负载而非只数节点。
- 如确需处理旧 CWYW 负载兼容性，仅在授权与可靠解析条件下迁移，保留有效的标准 CWYW 指令 XML、记录身份与显示结果，并原生打开验证；不能构造假字段绕过检查。不能安全保留时交付可定位的逐段/逐条替换稿并说明限制，不声称原文件已修好。
- 书签以名称、成对端点、实际语义范围及可解析目标为准；Word 重编内部数值 ID 不是丢失证据，但缺失名称、错位范围或断链必须修复。对已授权的目录/页码字段只规范化其结果差异，不扩大忽略范围。

## 4. 可见引文和文后版式双层验收

- 用户指定 GB/T 7714—2025 时，以[国家标准登记页](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=C6CE52E55AC09B9C79A20AEA77CEDD14)确认标准版本，具体著录规则核对标准正文。会议论文与整部会议录分开处理。逐条核对析出论文题名、作者、正式会议录题名、出版项、页码或文章号及适用的标识符。会议举办城市与出版地、会议日期与出版年不能互相推填，原始记录缺项时注明待核。
- 恢复引用前先找出来源实际支持的句子，按目标模板插入可更新的 CWYW 引文并核实可见上标。按所选著录制度双向核对：逐个解析正文的组合引文与编号区间，映射到文后条目；再从每条文献回查正文位置。重复记录、只有文后条目、缺少条目的引文及按规定单列的未引书目分别记录。
- 若 EndNote 将公式中的集合（如 `{0,1}`）当作临时引文，跳过该数学片段并核对目标引文域。保留集合符号及公式对象，勿从匹配列表中随选文献。

- 正文标记位置、字号、字重以当前校规/模板和作者要求为准，不能把某种期刊的行内引用或某稿固定上标字号套到所有论文。用户要求标记顶部与正文字顶对齐时，联合验证上标、引用字号及字符提升量，并在最终 Word/PDF 原尺寸查看；参数进入文档合同，不只凭 `superscript=true` 判通过。
- 只统计可见 `Field.Result`，保持原生引用；既有隐藏/抑制字段结果为空应单独记录，不计作可见引用未上标，也不能强制为其编填结果。检查多篇组合、区间、两位/三位编号、中文标点相邻位置，确保括号完整、顶端对齐且行距稳定。
- 文后分别检查编号列、编号后制表位、悬挂缩进、续行、字体字号、条目间距与跨页行。格式修复和元数据修正分别验收，不以文后看起来整齐证明文献真实或内容对应。
- 最终报告实际覆盖数、已修正项与一手依据，清楚区分真实性/著录核验、正文语义核验、内嵌记录保真、原库匹配。用户未要求或无法完成的层次不冒称通过；不在论文正文插入核验说明或虚构“全库一致”。
