# 正文内容生成学术框图工作流

本流程适用于“根据论文、Word、章节正文、公式或已确认示意图生成科研框图、方法图、残差图、因子图、技术路线图”的任务。它补充 `figure-workflow.md`，不得降低其中的文件隔离、原生对象、连接器、公式和最终审计要求。

## 1. 参数闸门

新章节、新主题、新参考图或主拓扑变化均视为新图任务。正式骨架前必须明确并冻结：

- 图的任务类型与正文范围；
- 参考图用于忠实复刻、风格参考还是仅作内容提示；
- 页面尺寸、方向、主图体宽高比与插入位置；
- 字体、字号、字重、配色和背景；
- 公式类型：Office 原生公式、MathType 或无公式；
- 目标 PPTX 绝对路径、目标页码和页面动作；
- 是否先看 SVG/PNG 预览，再写入 PPT。

用户已经明确的参数不得重复询问；未明确且会实质改变构图的参数必须先确认。除非用户明确说“沿用上一图”，不得跨章节继承比例、字体、字号、视觉语法或公式模式。

## 2. 正文证据锁

1. 读取目标 Word 或论文的权威章节、公式、图注和术语定义，不依据记忆或领域惯例补内容。
2. 建立正文—图示账本，逐项记录：`objectId`、可见文字或公式、对象角色、来源小节/段落/公式编号、正文原词、允许的压缩标签和是否冻结。
3. 图中对象名、时刻、帧、坐标系、地图、状态、残差、约束、版本和变量必须沿用正文当前版本。
4. 公式保持变量、上下标、集合层级、变换方向、坐标系和含义一致；正文未定义的符号、模块或机制不得自行加入。
5. 标签压缩只允许删减非核心修饰语，不得更换主语、对象、依赖关系或技术含义。任何“参考相机系 → 参考相机”之类的语义缩写都必须由正文或用户授权支持。

## 3. 内容压缩与骨架

1. 先把正文拆成“对象/输入—处理/约束—状态/中间量—输出/结果—反馈关系”账本，再选择拓扑。
2. 普通模块使用名词短语或必要公式，不把正文式解释塞进框内；用户要求“不要小字”时，删除非必要说明或扩大模块，不得降低字号。
3. 一张图只表达一个主逻辑。用户要求单一示意图时，不拆成三个解释框或多个竞争方案。
4. 先生成静态 SVG/PNG 骨架供用户确认。预览阶段冻结模块、主轴、分区、连接拓扑、主要图形、文本和公式位置；未确认前不得写入正式 PPT。
5. 用户给出批准图后，批准图成为视觉骨架；正文成为术语和符号权威。两者冲突时先说明，不得静默改写任一方。

## 4. Hybrid Reconstruction 对象分解

逐个对象分类，禁止整页截图或整组框图栅格化：

- 可读文字：独立 PowerPoint 文本框，使用用户确认字体字号；
- 公式：唯一命名目标槽，批量写入 PowerPoint Office 原生专业公式或已确认的 MathType OLE；
- 框体、标题栏、节点、坐标轴、直线、曲线、连接线和箭头：PowerPoint 原生 shape、连接器或单对象自由曲线；
- 独立图标：仅在必要且符合学术风格时逐个 SVG；用户提供的图标或线稿直接复用；
- 点云、地图、八叉树内部图、照片、实验图和无法可靠拆分的复杂局部：从批准图或用户素材中物理裁剪/抠出为独立图片层；
- 外部标题、文字、公式、箭头、边框和相邻对象不得保留在复杂图片裁剪中，必须由原生对象重建。

复杂局部的裁剪边界必须在放大图中检查。白底裁剪不得覆盖所属卡片的原生边框、箭头或文字。

## 5. 文本与公式排版

1. 先按固定字号测量 PowerPoint 最终字形，再确定文本框和卡片尺寸；禁止先画小框再缩字。
2. 文字和公式使用独立槽位。标题栏同时包含标题和公式时，至少划分“标题行—可见间距—公式行”，不得共享同一基线或相互覆盖。
3. 字形到容器四边至少保留当前字号 `0.5×` 的安全距离；紧凑框的正常留白不宜超过 `1.0×`。
4. 中文文本必须同时锁定普通字体和东亚字体字段为用户指定字体；例如宋体任务同时设置 `Font.Name` 与 `Font.NameFarEast` 为宋体。出现拥挤时按以下顺序修复：增大标题栏或文本槽 → 减小文本框内边距 → 扩大整组卡片或重新分配列宽 → 下移并缩小内部复杂图层 → 在授权范围内压缩非核心文字。不得单独缩小字号、使用任何负字符间距、硬回车碎行或遮罩。默认按 `Spacing = 0` 的真实字宽规划框体，禁止先用负字距压入窄框再声称字体字号合格。
5. Office 公式以最终插入对象的 `BoundTop/BoundHeight/BoundWidth` 为准，不以目标占位框估计。彩色标题栏中的公式颜色、位置和可见边界必须与批准图一致。
6. 每次公式写入后重新检查标题、公式、边框、箭头和相邻模块的 `3–4 pt` 可见安全距离。

## 6. 分层与边框

分层按组件语义处理，不能只执行一个粗略的全局顺序：

- 因子图或流程节点：`背景填充 < 连接路径 < 节点填充/轮廓 < 节点文字/公式`；
- 含复杂图片的卡片：`卡片底板 < 复杂图片 < 原卡片外框 < 标题栏/标题栏补片 < 标题文字 < 标题公式`；
- 页面级关系：箭头必须高于页面或分区背景，低于其连接节点和文字。

硬规则：

1. 复杂图片不得压住原生外框。卡片外框必须无填充，并在复杂图片之后置于前景。
2. 不得为解决遮挡再画第二个完整圆角边框；这会产生双线和双圆角。应直接调整原外框 Z 序。
3. 原外框置顶后，标题栏及其补片必须再次置于外框之上，避免外框顶边与标题栏圆角叠成双线；标题文字和公式最后置顶。
4. 边框、标题栏、标题文字和公式必须是独立对象；不得把它们烘焙进复杂图片。
5. 任何对象移动、裁剪、公式写入或局部修复都会使既有 Z 序审计失效，必须从最终保存状态重新检查。

## 7. 箭头与连接

1. 模块位置和中心轴冻结后再创建箭头。
2. 优先使用 PowerPoint 原生连接器并连接真实可见形状；箭头端点与框线不得有可见缝隙。
3. 水平或垂直直连先保证框体中心轴误差 `≤ 0.1 pt`，再连接真实边中点。
4. 折线、曲线和反馈路径必须是一条逻辑路径对应一个 PowerPoint 原生对象，不得拼接。
5. 保持批准图的数量、方向、虚实、颜色、箭头头部、弧向、拐点和源—目标拓扑。
6. 箭头宽度和头部按批准图或用户要求设置；不得用图片箭头、SVG 箭头或粗大块箭头替代原生连接器。

## 8. 隔离构建与写回

1. 先建立隔离工作副本和构建目录；目标 PPTX 在工作副本通过前保持不变。
2. 首次构建同时生成对象注册表、文字账本、公式清单、连接器账本、视觉覆盖账本和原生审计 manifest。
3. 复杂图片裁剪、原生对象搭建、公式写入、图层调整和审计都在同一权威工作副本完成。
4. 目标 PPT 未打开时，先创建即时备份再覆盖；目标 PPT 已打开且含未保存内容时，不得关闭或文件级覆盖。先 `SaveCopyAs` 保存用户当前状态，再仅替换授权页面、保存目标，并另存 QA 副本审计。
5. 禁止关闭其他演示文稿、退出 PowerPoint 或杀进程。

## 9. 最终检查

只审查最终保存状态，至少完成：

- PowerPoint 原生整页渲染与 100%–200% 高密度区域检查；
- 正文—图示账本逐项回查，确认术语、公式和符号完全一致；
- `text_overflow_count = 0`、无孤字/孤 token、无文字或公式碰撞；
- 外框连续、无图片遮挡、无双线/双圆角、标题与公式间距清楚；
- 连接器端点、身份、方向、共轴和代理锚点白名单通过；
- Hybrid 视觉覆盖对象数一致且问题数为 `0`；
- OOXML 无新增非公式结构错误；Office 公式 `AlternateContent` 的安全重复 ID 与普通结构错误分开处理；
- 最终图与批准图并排对照，确认结构、对象数量、复杂图形、颜色、文字、公式、箭头和留白无未授权偏离。

默认执行“一次完整构建 → 一次合并审查 → 一次集中修正 → 一次定向复查”。第二次复查后停止自动返工，除非用户明确授权继续。

## 10. 禁止项

- 未询问或确认新图的比例、字体、字号、参考图用途、公式类型和目标页；
- 根据常识改写论文术语、变量或公式；
- 把整图、整组模块、文字或箭头截图插入 PPT；
- 重画可直接裁剪复用的复杂点云、地图、八叉树或用户素材；
- 用图片、SVG 或拼接线段代替 PowerPoint 原生框、箭头、曲线和连接器；
- 通过缩小字号、负间距、遮罩、白底覆盖或重复边框掩盖碰撞和分层错误；
- 图片位于边框上方，或外框置顶后未恢复标题栏、标题文字和公式层级；
- 仅凭对象数量、占位框、缩略图或脚本成功判断图已合格。
