# 东南大学博士论文快速严格排版规则

在用户指定东南大学博士论文格式、引用学校格式规定，或要求修复该校论文 Word 排版时，完整执行本规则。用户当前明确指令始终优先于本文件。

## 1. 锁定正确源文件

1. 只使用用户本次指定的绝对路径或经根目录清单确认的原稿。文件名不完全一致时，先列出根目录实际 DOC/DOCX，再按准确名称选择；禁止根据“最新版”等历史称呼猜测。
2. 排除 `build/`、`output/`、历史修复稿、临时导出稿和 `~$` 锁文件，除非用户明确指定。
3. 写入前保存一次未修改备份和一个工作副本，并核对源文件、备份与工作副本哈希一致。原稿默认不覆盖。
4. 把用户指出的章节范围作为硬边界。只修改目标章节；目录、后续章节、参考文献和 EndNote 字段默认冻结。

## 2. 字体、字号和段落

| 对象 | 字体字号 | 对齐与段落 |
|---|---|---|
| 章标题（Heading 1） | 三号黑体，16 pt | 居中，首行缩进 0 |
| 节标题（Heading 2） | 四号宋体，14 pt，加粗 | 左对齐，首行缩进 0 |
| 节内小节（Heading 3） | 小四黑体，12 pt | 左对齐，首行缩进 0 |
| 正文 | 小四宋体，12 pt | 两端对齐，首行缩进 2 字符，1.5 倍行距，段前后 0 |
| 图题、表题 | 五号宋体，10.5 pt | 居中，单倍行距，首行缩进 0 |
| 表内文字 | 小五宋体，9 pt；确有需要时可用正文大小 | 单倍行距，段前后 0；短标签和数值居中，长文本按原意左对齐 |
| 表注 | 小五宋体，9 pt | 左对齐，单倍行距，段前后 0 |

- 将中文、英文、数字的 `ascii`、`hAnsi`、`eastAsia` 和 `cs` 字体统一设为宋体，除非公式、变量、用户冻结内容或学校模板另有明确要求。
- 保留原有加粗、上下标、斜体变量和数学字体语义；不得为了统一字体破坏公式或实验最优值加粗。
- 图表题名统一为 `图3-7 题名`、`表3-7 题名`：标签与章号之间无空格，编号使用短横线，编号后保留一个半角空格。禁用题注段落的 `autoSpaceDE` 和 `autoSpaceDN`，避免 Word 显示成 `图 3-7`。
- 图题置于图下，表题置于表上；表注必须位于同一无边框文本框内，顺序为“表题 → 表格 → 表注”。

## 3. 分页控制

按对象分别设置，禁止全章统一打开或关闭分页选项。

| 对象 | 段前分页 `pageBreakBefore` | 与下段同页 `keepNext` | 段中不分页 `keepLines` |
|---|---:|---:|---:|
| 章标题（Heading 1） | 开 | 开 | 关 |
| 节标题（Heading 2） | 关 | 开 | 关 |
| 小节标题（Heading 3） | 关 | 开 | 关 |
| 正文 | 关 | 关 | 关 |

- 章标题必须另起新页并至少与下一段同页；其他标题不得悬挂在页底。
- 正文不得形成 `keepNext` 链，也不得用 `keepLines` 把整段推到下一页。
- 图题、表题和表注位于固定文本框时，不用正文分页链控制对象完整性；由文本框几何、锚点和环绕方式保证完整。
- 章末因下一章“段前分页”留下的少量自然余白不等于空白页。若整页无正文、图表或合法分页对象，必须继续追查。

## 4. 紧凑排版与空白区域

1. 先定位空白来源：手动分页符、`pageBreakBefore`、`keepNext`、`keepLines`、分节符、固定文本框高度、锚点、环绕方式或表格固定行高。禁止直接缩小全文字号。
2. 删除目标章节内真正无内容且无锚点的空段。若段落包含图片、文本框、公式、字段、书签、分节属性或合法分页符，不得删除。
3. 清除空项目符号、空编号段和纯占位段；不得删除公式占位、图片锚点或隐藏的合法编号锚点。
4. 表格使用自然行高，移除导致裁切或大块空洞的固定行高；保持原始数据、列顺序、单位、精度、失败标记和加粗语义不变。
5. 不改变图片宽高比。只有对象确实超出版心时才等比缩小，禁止为压页拉伸、裁切或改变图体比例。
6. 大图、整页图表和连续固定对象可能产生不可避免的页尾余白。先尝试稳定锚点、缩短文本框空高度或在不改变比例的前提下等比缩小；不能消除时如实保留，不用负间距、隐藏文本或跨页重叠吸收。

## 5. 图表、文本框和公式编号

- 单页图、单页表、题注和不可分离注释放在同一个无边框固定文本框中；不改变已有图片比例和表格数据。
- 文本框宽度不得超过活动节版心，内部边距取满足显示的最小稳定值；渲染确认最后一行、题注和表注均未裁切。
- 表格行距、列距过大时，先清除单元格段前后距和固定行高，再调整内边距；不要盲目压缩列宽或缩小到不可读字号。
- 公式编号位于独立右侧区域并保持单行。若 `(3-26)` 等编号被拆行，给编号单元格设置 `noWrap` 并适度加宽编号列，同时等量缩减公式列；不得修改公式内容或让整表越出版心。

### 5.1 图表后不得出现空行

1. 图题、表注后的下一段必须直接进入正文或下一个合法对象，不得插入可见空段、空项目符号、空编号段或只含换行符的占位段。
2. 固定文本框末尾删除多余空段；表格结尾若 Word 强制保留空载体段，只保留一个无文字载体，并设为段前后 0、精确 1 pt、无编号、无边框。
3. 仅含图表文本框的外层锚点段落设为段前后 0、精确 1 pt、首行缩进 0；锚定对象的 `distB` 设为 0。若外层段落还包含正文，必须先拆分，禁止把正文压缩成锚点载体。
4. 最终在显示编辑标记状态下检查：图表后不得出现空段落标记；正常打印布局中不得出现由文本框空高度、锚点行高或环绕下距造成的空白行。

### 5.2 数据表三线表美化与完整性

1. 修改前先执行[Word 表格对象分类与变更阻断闸门](table-object-classification-gate.md)。本节只适用于语义数据表，不适用于公式编号、封面、图片拼版或题注/表注布局表；禁止对全部 `<w:tbl>` 统一套用。
2. 数据表统一为完整三线表：顶线、底线为 1.5 pt，最后一层表头下方分隔线为 0.75 pt；删除左右边线、所有竖线、数据行内部横线、斜线和非必要底纹。用户明确指定其他线宽时，以排版合同中的覆盖值为准。
3. 多层表头只在最后一层表头下画分隔线；跨页续表重复完整表头。合并单元格不能导致顶线、表头线或底线断裂，必要时同时设置表级边框与相应行的单元格边框以保证通栏连续。
4. 清除固定行高，允许自然增高；表内小五号宋体、单倍行距、段前后 0。单元格上下内边距取紧凑一致值，左右内边距按内容留出最小可读空间；短字段和数值居中，长说明左对齐。
5. 列宽按内容自动优化，但不改变列顺序与合并关系。优先压缩短字段列并给长表头/长文本列留宽；出现拥挤时依次采用换行、调列宽、微调内边距，禁止先缩小到不可读字号。
6. 数据表优化必须保留原始数据、单位、精度、失败标记、加粗最优结果和表注。任何残留底纹、竖线、分段底线、过大行列间距、裁切或挤压均视为未完成，必须修复后重新渲染。

## 6. 快速执行路径

1. **只读确认**：核对源文件绝对路径、章节边界、标题样式 ID、图表题名、分页标记和保护对象数量。
2. **一次集中修改**：在一个工作副本中批量应用标题、正文、图表题名、表格和分页规则；不得每修一处就重新导出全文。
3. **结构保真检查**：要求公式、图片、媒体哈希、表格数据、超链接、书签、字段、`ADDIN EN.CITE` 和非目标包部件保持不变；允许的变化仅限授权格式、题注编号空格/分隔符和确认可删的空段。
4. **定向渲染**：先检查章起始页、章末页、标题跨页处、图表密集页、最稀疏页和长公式编号页；出现问题时只修受影响对象。
5. **一次最终验证**：最终保存后再渲染目标章节及其前后边界页，检查无标题悬空、无真正空白页、无裁切溢出、无公式编号换行、无图表失真。
6. **交付副本**：输出文件名明确标记章节范围和学校格式；不覆盖原稿，除非用户明确要求原位保存。

## 7. 禁止事项

- 禁止误用历史中间稿或仅因文件名包含“最新版”就选作源文件。
- 禁止把所有标题和正文统一设为“与下段同页”，也禁止全部关闭。
- 禁止用“段中不分页”保持正文整段完整。
- 禁止更新目录、全部字段或 EndNote 来证明排版成功，除非用户明确授权。
- 禁止以联系表缩略图代替对小字、题注、公式编号和空段的原尺寸检查。
- 禁止声称“无空白页”而未检查目标章节全部页面和章节边界。
