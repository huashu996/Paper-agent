## 适用范围与优先级

当任务需要撰写、扩写、改写或润色中文博士、硕士或本科毕业论文正文时，完整读取并执行本规范。纯排版、纯公式、纯引文整理或不产生中文正文的任务不触发。

优先级固定为：用户本轮明确要求 → 学校、期刊或目标文档模板 → 项目 `style/` 中已确认规则 → 目标文档邻近正文的术语与语气 → 本规范。目标文档已经稳定采用“实验”或“试验”时沿用原词，不得在同一文档中混用。

本规范只约束表达，不授权补造数据、机制、实验、比较方法、引文或结论。样文中的重复词、空格异常、术语不一致、语病和证据不足的拔高表达不得继承。

## 总体语体

- 使用客观、克制、问题导向的学术陈述。优先使用“本文”“本章”“本节”“该方法”“所提框架”，不使用“我/我们认为”、口语、反问、感叹或宣传性措辞。
- 以研究对象和证据为主语。采用“针对……问题，提出/构建/设计……”“结果表明……”“该现象说明……”等可核验表述。
- 组织正文时先交代问题或目的，再说明输入、条件、动作和输出。方法叙述体现因果关系，实验叙述体现证据关系。
- 将“测试、评估、验证、分析”区分使用：测试是执行活动，评估是按指标衡量，验证是证据支持主张，分析是解释结果。实验结果通常“表明、验证或支持”主张；除数学定理外，不轻易使用“证明”。
- “显著、有效、优异、最佳、鲁棒、全面”等评价词必须有相邻的数值、图表、统计检验或明确比较对象支撑。证据只支持相关性时，不写成确定因果。
- 术语首次出现采用“中文名称（English Name，缩写）”，后文统一使用一个简称。方法名、数据集名、符号、单位和图表编号必须与正文、图表和公式一致。

## 句子、标点与段落

### 句子节奏

- 默认以 `45–75` 个中文字符构成一个完整陈述；复杂因果句可适当延长，但超过约 `100` 个中文字符时优先在证据、转折或结论处断句。
- 一个句子只承担一个主要判断。可用逗号连接条件与动作，用分号连接两个内部结构复杂且地位并列的分句，用句号结束一个完整论证单元。
- 避免连续三个以上“的”字结构、连续多个“通过……实现……”以及同一句中反复出现“本文/所提出的”。压缩修饰语，但不省略主语、比较对象和作用边界。
- 使用主动逻辑，不堆叠名词。例如先写“引入场景滤波模块，以抑制动态干扰”，再写其作用；不要把所有模块、条件和效果压成一个超长定语。

### 标点

- 中文正文统一使用全角 `，。；：、（）“”`。不用问号、感叹号制造语气，不用英文逗号或句点结束中文句子。
- 冒号只用于引出公式、定义、清单或下文解释。分号只用于长并列项或章末并列总结，不用分号代替普通句号。
- 图表引用写成“如图3.2所示”“由表4.1可知”或目标文档既有格式；图号、表号前后的空格服从目标文档，全文保持一致。
- 复合技术名中的连接号沿用领域和目标文档约定，如“相机-激光雷达”“帧-地图”；不要混用连字符、破折号和减号。
- 列举研究内容、贡献或实验条件时使用 `（1）…；（2）…；（3）…。`。并列项内部已有逗号时用分号分隔。
- 数值与单位、百分数、小数位和正负号服从数据源与目标模板。禁止为了行文流畅改写精度、单位或失败标记。

### 段落

- 每个实质段落围绕一个中心任务组织为“主题句 → 条件/机制或证据 → 解释/边界 → 过渡”。通常写 `2–4` 个句子、约 `120–260` 个中文字符。
- 同一因果链不拆成连续的一句式微段落；研究对象、因果阶段、公式组、实验任务或论证方向改变时才分段。
- 每个方法或实验小节先有一段完整引入，不以公式、变量清单、表格、图题或孤立的“如图所示”开头。
- 图表前说明为什么需要该证据及其设置，图表后解释观察、幅度和意义。不得用图表标题的同义改写充当正文分析。

## 前后衔接

### 小节内部

按下列关系选择连接词，不机械轮换：

- 目的与问题：`针对……问题`、`为了验证……`、`为评估……`。
- 条件与组成：`其中`、`具体而言`、`分别`。
- 顺序与递进：`首先`、`其次`、`进一步`、`在此基础上`、`进而`。
- 因果与结果：`因此`、`从而`、`由此`、`这表明`。
- 对比与转折：`相较于`、`相比之下`、`然而`、`尽管……但……`。
- 证据指向：`如图…所示`、`由表…可知`、`实验结果表明`。
- 收束：`综上`、`总的来说`、`上述结果表明`。

同一段内同一连接词原则上只出现一次；相邻段落不要连续用“首先”“此外”“综上”起句。`可以看出` 只用于直接可观察结果，不能代替具体数值和解释。

### 小节之间

- 新小节首句先承接上节已获得的模型、变量、实验结论或尚未解决的问题，再说明本节为何继续。
- 从仿真转向硬件在环或实车时，明确证据升级关系：仿真验证可控条件下的性能，硬件在环验证实时闭环与工程实现，实车验证真实扰动和应用边界。
- 从基准测试转向泛化、大范围、压力或长期实验时，先指出已有测试覆盖范围，再指出仍缺失的维度，最后给出新增实验的验证目标。
- 小节末句为后文提供接口，不重复标题。写清本节输出将用于哪个后续模块、实验或结论。

## 实验叙述

### 实验小节开篇

按“验证目的 → 平台与数据 → 对比方法 → 指标 → 公平条件 → 参数/图表入口”组织，资料缺项时如实保留缺口，不自行补齐。

推荐句群骨架：

1. `为了验证所提方法在……条件下的……性能，本节基于……平台/数据集开展……测试。`
2. `其中，……用于生成/采集……，算法运行于……；主要参数见表X，平台组成如图Y所示。`
3. `为进一步评估……，选取……作为对比方法，并采用……作为评价指标。`
4. `所有方法使用相同输入、数据划分、硬件或参数口径，以保证比较公平。`

不得把平台、传感器、数据集、基线、指标和参数无层次地堆在一个超长句中。首次出现的数据集按实验工作流完整介绍；后续出现只说明本章复用目的和验证作用。

### 结果分析段

每个结果段按以下证据链写作：

1. **定位证据**：指出具体图、表、子图、序列、工况或指标。
2. **陈述事实**：先给趋势、排序或异常，再给关键数值与单位。
3. **量化比较**：写清基线、本文方法、变化方向和幅度；百分比必须能由原始值复核。
4. **机制解释**：只使用方法章节已建立或实验可分离的机制；无法独立验证时用“可能与……有关”，不得写成已证实因果。
5. **边界与异常**：说明失败、波动、代价、适用条件或仍未分离的因素。
6. **局部结论**：只收束到当前指标和工况，并为下一项实验建立接口。

结果段不得只写“本文方法最好”。至少回答：好在哪里、相对谁、差多少、在什么条件下、为何可能如此、代价或边界是什么。

### 不同实验类型

- **定量对比**：按统一指标和场景顺序比较；先整体结果，再分析最有代表性的场景、异常场景和失败场景。
- **定性结果**：指出图中可定位的轨迹、边缘、重影、漂移、完整性或局部结构，不使用“效果更好”等无法复核的视觉判断。
- **消融实验**：先说明基框架和模块组合，再比较相邻配置。只有控制变量充分时才归因于单个模块；组合增益不得写成独立贡献。
- **泛化实验**：说明变化维度，如传感器线束、平台、天气、运动、场景或尺度，并逐项对应验证结论，不以“数据集很多”代替泛化证据。
- **效率与资源**：同时报告硬件、运行时间/频率、内存或通信量和精度权衡；“实时”必须有任务频率或延迟依据。
- **压力、长期与大范围实验**：交代扩展倍数、持续时间、累计里程和新增困难，区分稳定运行、精度保持与偶发失败。
- **失败与局限**：按“触发条件 → 可见症状 → 已有证据支持的原因 → 对结果的影响 → 当前缓解措施或未来验证”描述。

### 实验证据的递进

优先形成“受控仿真/公开基准 → 消融 → 不同工况或跨平台 → 硬件在环/真实数据 → 泛化、压力、长期或大范围 → 效率与局限”的递进链。只写已有证据覆盖的层级，不为追求完整结构虚构实验。

## 章末小结

- 章末小结通常为 `1–2` 个完整段落，不新增方法、数据、引文或未经正文分析的结论。
- 第一段按技术路线回收本章：`本章针对……，提出……。首先……；其次……；在此基础上……。`
- 第二段回收证据和边界：`实验/试验结果表明……`，随后说明适用条件、代价或局限；若后续章节使用本章输出，最后一句明确该接口。
- 不逐节抄写标题，不重复摘要式口号，不把候选贡献写成已经充分证明的创新。

## 禁止模式与审查清单

### 禁止模式

- 连续使用“本文提出”“可以看出”“实验结果表明”而不提供新信息。
- 只引用图表编号，不解释关键观察和意义。
- 先写机制结论，后找数值佐证；或把相关性写成因果性。
- 用“明显、较好、极大、充分证明”等模糊程度词代替数值。
- 多个一两句微段落、项目符号式正文、口语化转折或宣传式结论。
- 混用“实验/试验”、同一术语的多个译名、不同图表编号格式或全角/半角标点。
- 在小结中首次出现新结果、新比较、新数据集或新机制。

### Reviewer 必查

- 每个段落是否只有一个中心任务，并形成主题、证据/机制、边界或过渡。
- 每项实验主张是否能定位到具体图表、工况、指标和数值。
- 每个结果段是否同时包含事实、幅度、解释和适用边界；证据不足时是否降低措辞强度。
- 消融结论是否由控制变量支持；组合效果是否误写成单模块贡献。
- 图表前后是否形成“前文主张 → 图表证据与观察 → 对方法或结论的影响”。
- 相邻小节是否有承接句，章末是否说明后续接口。
- 是否存在问号、感叹号、英文标点结束中文句、重复连接词、超长句和连续微段落。
- 数据、单位、精度、方法名、图表号、公式号、实验/试验用词是否与目标文档一致。

## 风格标定来源

公开版本仅保留通用语言、标点、分段、衔接与实验叙述规则，不包含个人论文、样文章节、论文题名或页码。

实际任务中，优先采用用户明确授权的样文和目标文档邻近正文进行风格标定。样文只用于学习表达，不自动构成事实、数据、公式或引文来源。
