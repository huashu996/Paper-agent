# 版式优先与纵向页面阻断闸门

## 适用范围

只要用户已经指定学校或期刊模板、页面方向、页边距、表格线宽或其他版式参数，后续对同一 Word 论文的正文、图、表、公式、引文和目录修改均执行本闸门。局部内容修改、红色意见修订和提交前检查均不例外。

## 写入前冻结

1. 把用户第一次确认的模板及之后的覆盖值登记为持续有效的排版合同，不要求用户重复说明。
2. 保存只读基线与唯一工作副本，记录目标文件 SHA-256；同时登记节数、每节纸张尺寸与方向、页边距、页眉页脚、页码、目录、封面、数据表、公式布局表、图片拼版、题注、表注、EndNote 域和媒体映射。
3. 建立最小修改白名单。正文优化不授权改封面、数据表、公式编号容器、图片拼版或参考文献版式；“修复表格排版”只授权语义数据表，不授权公式、封面和图片布局表。
4. 页面方向默认冻结。用户未逐节明确要求横向时，全部正文页保持模板规定的 A4 纵向，禁止因宽表、长公式或图片直接新增横向节。

## 宽对象的纵向适配顺序

宽表或宽图超出版心后，依次采用以下办法，并在每一步后渲染受影响页：

1. 保持对象身份、数据、列序、合并关系、加粗语义、题注和表注不变，先按内容重新分配列宽并压缩非必要单元格内边距。
2. 对同类长表头按相同语义边界显式换行；禁止依赖 Word 随机换行造成同列行数混乱。
3. 对多指标横向宽表，可在同一方法列内按固定顺序纵向堆叠指标，并在表头或表注明确指标顺序；不得删列、删行、改数值或把表格栅格化。
4. 仍无法容纳时拆成带重复完整表头的连续语义分块，并保持表题、续表标识和表注关系清楚。
5. 只有用户明确授权某一节横向时才可改变方向；不得把“排版优化”“表格美化”或“可提交版”解释为横向授权。

不得通过缩小到低于排版合同字号下限、拉伸图片、裁切内容、隐藏文字、负间距、删除表注或破坏公式编号来压页。

## 对象保真

1. 对 `<w:tbl>` 或 `Document.Tables` 的全局操作为阻断错误。先按数据表、公式布局、封面布局、图片布局、题注/表注容器和未知对象分类，未知对象冻结。
2. 公式必须保留 Office 原生 OMML、编号和布局容器；写入前后比较公式总数、空公式数、字段数及抽样渲染。空公式、乱码、编号换行或公式被边框包围均不得交付。
3. `mc:AlternateContent` 的 `Choice` 与 `Fallback` 按一个可见对象审计，不得误判为两张表后删除、拼接或重排。
4. 数据表只按排版合同处理三线边框。用户覆盖值如“顶线和底线 1.0 pt、最后一层表头线 0.5 pt”必须持续继承；无竖线、无逐数据行横线、无双线。多层表头以最后一层表头的完整通栏边界为准。
5. 表中 XML 存在末行不代表版面完整；必须放大检查最后一行、通栏底线和表注均实际可见且对齐。

## 保存与整页验收

1. 只在工作副本上修改，完成一次主要 Word 保存并更新本次明确授权的目录字段；禁止连带刷新 EndNote 或其他冻结字段。
2. 先渲染受影响页及相邻页，放大检查表头、最后一行、公式、题注和正文衔接；联系表只能用于导航。
3. `submission` 档最终必须导出整篇 PDF 并逐页巡检，同时执行两层方向审计：
   - Word 层：每个 `w:sectPr/w:pgSz` 都满足宽小于高，且不存在 `orient="landscape"`；
   - PDF 层：每页 MediaBox 宽小于高、旋转角为 0，纸张尺寸统一为模板规定的 A4，横向页数量为 0。
4. 对最终 PDF 运行边缘接触和近空白页检测；所有命中页逐页解释并放大复核。图表、公式或文字触碰版心边缘、被裁切、错页、重叠或消失均为阻断错误。
5. 最终比较基线与候选稿：非白名单对象差异数、丢失对象数、空公式数、横向节数、横向 PDF 页数和无解释异常页数必须均为 0。
6. 覆盖用户指定目标前重新核对目标 SHA-256，确认用户未在处理期间另行修改；只有候选稿全部通过后才允许写回。写回后再次核对哈希与 Word 包完整性。

任一阻断项失败时保留目标原稿，修复工作副本并重新完成整页验收，不得交付“结构正确但页面仍错”的文件。
