# 用当前论文的证据解释实验

适用于起草实验分析、修订已有讨论和制作答辩实验页。目标是让读者理解实验检验了哪个问题、所得结果支持哪些判断，以及这些判断在哪些条件下成立。

## 先弄清实验回答什么

依次核对本组实验的方法设计、实际设置、数据来源、对照配置、评价指标和结果图表。记下能支持解释的具体位置，例如表中的一个条件组合、图中的一段变化或原始记录中的一次事件。全文任务要逐组覆盖，局部修订则围绕用户指定的问题进行。

区分方法公开描述、作者本次实现、实际启用的选项及本次运行的表现。方法名和样本名不能用来代替配置与场景依据。需要补证时，查对应版本的原始论文、官方数据说明或作者实现；外部文献只能说明其记载的条件，当前实验仍以作者材料为准。作者确证的现场观察可解释对应片段，不能据此补写未记录的采样时刻、运行日志或实验。

## 从观察写到判断

| 需要回答的问题 | 可用的依据与写法 |
|---|---|
| 比较的条件相同吗 | 先对齐输入、预算、划分、指标定义和统计样本。比较均值时检查分母、缺失样本与失败处理。不同条件各自支持的判断应分开陈述。 |
| 哪项变化值得解释 | 选能回答研究问题的指标，指出差异方向、条件及范围。结合可定位的图形证据或独立记录。相同数据的图和表可以帮助阅读，但不能当作两次独立试验。 |
| 这种变化与设计有何关系 | 指出工况改变了哪类输入、约束或代价，再联系方法中相应的处理环节。观察与原理相符时可说明这种一致性；宣称某项改动导致差异，需要能区分它与其他变化的依据。 |
| 消融能否分辨各项贡献 | 核对相邻配置及保持不变的条件。只有一项因素发生变化时，可讨论它在这些条件下的作用。多项同时改变时，只讨论组合配置的结果。 |
| 结论适用于哪里 | 选择典型、异常、失效或未占优的条件深入讨论，其余样本归纳共同特征。区分总体结果、已有局限和未经验证的推广，保留有充分证据的明确判断。 |

正文按本组实验最需要说明的问题展开，段落不必重复同一套步骤。先说比较目的，在段中自然引图或表，继而解释读者能在哪里看到什么。对原因尚有多种解释时，指出还需要哪类对照才能判别。正式页不放制作留言，不能解释的矛盾在修订记录中说明，保留正文能够成立的观察。

## 保持作者的判断与材料边界

如提供了获准参照的样文，可学习作者如何从具体困难引入比较、如何承接异常以及如何措辞。另一项研究的术语定义、实验配置、结果与结论须独立核实，不能迁入当前论文。用当前对象作主语，直接说明观察或动作。只有多个因素确有不同作用时才逐项展开，同一概念沿用同一名称。内容决定句长和段数。

## 保存后核验

- 对照源表、图例、单位、配置和原稿，核对每项新增解释所引用的事实，保留引文域、原图、公式、编号及未授权修改的前置页和分节。
- 涉及公式字形时先在副本中选取代表式试改、渲染，核对符号、上下标及具有数学意义的字形，再按授权范围处理。文件里的字体属性不能代替渲染和可编辑性验证。
- 在实际保存的论文中查看改动页及相邻页，检查图文顺序、公式显示和合法留白。用户只要 Word 时，可取 Word 页面图像核验；若明确禁止生成 PDF，遵守该限制。
- 答辩实验页使用当前明确版本的论文，复核其证据、口径和结论边界。论文尚在修订时，记录所据版本，交付前检查两者是否同步。
