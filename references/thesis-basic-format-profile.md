# 从参照论文提取 Word 基础格式

作者要求沿用一篇论文的格式时，对照原文件只读提取，用 Word 对话框中可直接设置的单位记录。若另有适用的学校规范或作者指定值，分别记录三者的来源与优先级。一篇参照稿的常见做法不能独立证明学校要求如此排版。

## 确认实际生效的格式

按节记录纸张、方向、版心、分栏、装订线、页眉页脚距离、页码起点和续编方式。区分封面、前置部分、正文与附录。核对实际样式继承链、文档默认值、主题字体、直接格式与编号定义。样式面板中的名称本身不足以确定某个字的实际字号。

分开抽取章标题、各级节标题、正文、脚注、题注、表内文字、参考文献和目录条目；区分中文、西文、数字、符号。各类分别取最常见的有效设置，并注明有意的例外。并列出现的两种版式先判断是否承担不同功能，避免用平均值生成原稿不存在的设置。

## 记录可复用的参数

| 对象 | 记录要点 |
|---|---|
| 标题与正文 | 字体、磅值、加粗、缩进、段前段后及其单位、行距类型、文档网格、分页与大纲级别。 |
| 图表 | 对象、题注和正文交叉引用分别取样；记录图表对齐、表头重复、边框、单元格内边距及跨页方式。 |
| 公式 | 区分 OMML、MathType OLE 和图片。记录公式段、编号位置和制表位；只读 XML 无法解析的对象内部字号列为待核。 |
| 自动域 | 记录目录、页码、书签、交叉引用、引文对应的域种类及可见结果。区分域结果的直接格式和继承格式。 |

生成格式指南时说明取样类别、有效参数和例外，保留原件。任务也要求应用这些设置时，另存工作稿；从最终保存状态核对分页、题注、公式编号和实际字号。向作者区分已经核实的版面和只能从文档结构推断的部分。
